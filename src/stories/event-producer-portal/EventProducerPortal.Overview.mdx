# Event Producer Portal — V1

The **client-facing event portal** an Event Producer sees for their event —
recreated on the EventPipe design system. Lighter top-bar chrome (no internal
admin sidebar), a full event-detail header, and three tabs: **Hotels · Group
Blocks · Reservations**. The Reservations tab is the launch point for the
**Bulk Edit** wizard.

Built for the Varsity / Team Travel Source demo. All data is fake.

## ▶ Pilotable prototype (start to finish)

A standalone, clickable prototype is deployed alongside Storybook on GitHub Pages:

- **Live:** [https://epprestodesign.github.io/eventpipe-prototype-ds/prototype/#/event-producer-portal](https://epprestodesign.github.io/eventpipe-prototype-ds/prototype/#/event-producer-portal)
- **In Storybook:** the [Prototype — Full Flow](?path=/story/event-producer-portal-event-producer-portal--prototype) story runs the same self-contained component with no page reloads.
- **Local dev:** `pnpm dev:prototype` → `http://localhost:6007/#/event-producer-portal`.

Both the prototype and the story mount `src/components/EventProducerPortalFlow.vue`
— the single element that owns the whole portal + flow.

## What changed for V1 (from the demo feedback)

- **Removed the "Reserved On" column** — its wide footprint forced horizontal
  scrolling. The default column set now fits without scroll.
- **Editing restricted to guest _name_ and _email_** for the initial release
  (Bulk Edit offers *Edit Names* / *Edit Emails* only; all other columns are
  read-only). This will expand post-launch.
- **Standardized placeholder data** — **Staff Member 1–50**, all sharing one
  email address (`staff@teamtravelsource.com`).

## Reused design-system elements

`DsPageHeader` · `DsInfoGrid` · `DsStat` · `DsThumbnail` · `DsModal` — plus the
shared `.ds-table`, status pills, stepper, pagination, and Edit-Columns patterns
carried over from the Bulk Reservation Edit flow.
